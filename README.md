# つりスピ！ちゃお ★ さかなつりゲーム ★

子ども向けシンプル魚釣りゲームです。Python + Pygame で動きます。

## あそびかた

1. 画面の **さかな** をクリック（タッチ）する
2. そのまま **うえのバケツ** まで ひっぱる
3. バケツに入れると **つりせいこう！** ★

## きどうほうほう

```bash
pip install pygame numpy
python main.py
```

## ファイルこうせい

```
project/
├── main.py         ゲームのきどうポイント
├── game.py         メインゲームロジック
├── fish.py         さかなクラス（5しゅるい）
├── gauge.py        はなまるゲージ
├── particles.py    かみふぶき・ほしエフェクト
└── assets/
    └── fish/       さかなのPNG画像をここにおく（なくてもうごく）
```

## さかなの画像をじぶんで用意するとき

`assets/fish/` フォルダに以下の名前でPNGをおいてください（透過背景推奨）：

| ファイル名 | さかな |
|---|---|
| `kumanomi.png` | クマノミ |
| `kakure_kumanomi.png` | カクレクマノミ |
| `hirame.png` | ヒラメ |
| `manta.png` | マンタ |
| `same.png` | サメ（ボス） |

画像がない場合は、いろつきのキャラクターで自動的にひょうじします。

### ChatGPT・Midjourneyでの画像作成プロンプト例

```
クマノミ、かわいいキャラクター風、クレヨンタッチ、
白背景（透過用）、横向き、シンプル、子ども向けイラスト、PNG
```

## さかなのしゅるい

| なまえ | おおきさ | はやさ | はなまるゲージ | でやすさ |
|---|---|---|---|---|
| クマノミ | 小 | はやい | +10 | おおい |
| カクレクマノミ | 小 | はやい | +10 | おおい |
| ヒラメ | 中 | ふつう | +20 | ふつう |
| マンタ | 大 | おそい | +30 | すくない |
| サメ（ボス） | とくだい | おそい | ゲージリセット | ゲージMAXのときだけ |

## ゲームのながれ

1. ふつうにさかなをつる → スコアとはなまるゲージがふえる
2. ゲージが **MAX** になると「すごい おおもの チャレンジ！」バナーがでる
3. **サメ（ボス）** があらわれる！つりあげると「はなまる！」エフェクト
4. ゲージリセットして また1からスタート
